Research

The Problem We Solve

Traditional financial chatbots face a fundamental tension — the Accuracy-Diversity Trade-off. They either over-specialize in user preferences, creating echo-chamber portfolios, or fail to enforce strict fiduciary risk constraints required for responsible wealth management.

WealthNexus addresses this with a Hybrid Adaptive Routing mechanism that distinguishes between routine informational queries and complex advisory tasks. Simple questions take a fast keyword path; nuanced intent escalates to a zero-temperature LLM classifier.

For portfolio recommendations, the system employs a supervisor-led subgraph that integrates Modern Portfolio Theory (MPT) as a re-ranking constraint — ensuring outputs are not only semantically relevant but mathematically optimized for risk diversification, effectively reaching the efficient frontier of automated advisory.

Hybrid Adaptive Routing
Two-tier intent classification via LangGraph — keyword fast-path for routine queries, LLM fallback for complex advisory tasks.
MPT Re-ranking Constraint
Modern Portfolio Theory applied as a post-retrieval filter — recommendations are optimized for the efficient frontier, not just semantic similarity.
Transparent Reasoning Paths
Real-time reasoning path visualizations surface how decisions are made, fostering user trust in automated financial advice.
Agentic Orchestration + Classical Finance
Synthesizes LLM-based multi-agent coordination with established financial engineering theory for a scalable, verifiable advisory model.

User Guide

Getting Started

Everything you need to start using WealthNexus — from initial setup to navigating each module.

1
Initial Loading

When you first access the application, it may take a moment to load. Please wait while the environment initializes.

2
Adjust the Display

Resize or zoom the interface to your comfort. You can use Ctrl + scroll, browser zoom, or drag-to-resize as needed.

3
Enter Your API Keys

Locate the API Keys panel in the bottom-left corner. Enter your API key(s) there. The application will use the LLM model associated with the key you provide.

⚠ In a production deployment, API keys would be stored securely in a .env file rather than entered through the UI.
